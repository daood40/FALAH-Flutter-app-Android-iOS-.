## ١ · المهمّةُ العالقة: الدفعُ إلى GitHub

**الحالة: لم يتمّ بعد.** المستودعُ الهدف:

```
daood40/FALAH-Flutter-app-Android-iOS-.
```

### ما تحقّق بالاختبار لا بالظنّ

| السؤال | الجواب | كيف عُرف |
|---|---|---|
| هل الاسمُ ينتهي بنقطة؟ | **نعم** | استعلامٌ مباشرٌ عن المستودع |
| هل هو موجود؟ | **نعم** | `git ls-remote` نجح |
| هل هو فارغ؟ | **نعم** | `ls-remote` لم يُعِد أيَّ ref |
| هل هو عامّ؟ | **نعم** — ولم يُجعل خاصًّا بعد | استعلامٌ مباشر |

### لماذا فشل الدفع

الجلسةُ السابقةُ تعمل في بيئةٍ معزولةٍ يمرّ خروجُها إلى GitHub عبر
**وسيطٍ (proxy) تملكه المنصّة**. يحمل الوسيطُ قائمةَ مستودعاتٍ مأذونةً
لكلّ جلسة، **تُقرأ مرّةً واحدةً عند بدء الجلسة**. القراءةُ تمرّ للجميع،
أمّا الكتابةُ فلا يُحقن لها اعتمادٌ إلا لمستودعٍ في القائمة.

الرسالةُ الحرفيّة عند كلّ محاولة:

```
remote: access denied by the git proxy:
daood40/FALAH-Flutter-app-Android-iOS-. is not in this session's
authorized repository set, so the proxy will not inject a credential
for it. To fix, add the repository to the session's sources.
fatal: ... error: 403
```

جُرِّب أكثر من ستِّ مرّات، وبرمزٍ شخصيٍّ من المالك أيضًا: **الرمزُ يصل
GitHub للقراءة ولا يصل للكتابة** — يُنزع قبل أن يخرج الطلب.
وإضافةُ المستودع إلى مصادر الجلسة **بعد بدئها لا تؤثّر في الجلسة الجارية**.

### ما رُفض عمدًا — ويبقى مرفوضًا

الالتفافُ على الوسيط بأيّ وسيلة، ومنها SSH. **هذا ضابطُ منصّةٍ لا يرفعه
إذنُ المالك**، فلا تحاوله ولا تقترحه.

### ما ينفع

1. **جلسةٌ يكون المستودعُ في قائمتها منذ البدء** — عندها يُدفع مباشرةً.
2. **الاستيرادُ من المتصفّح** — `launch/import-workflow.yml` (انظر §٣).
3. **Termux على الهاتف** — [`STEPS.md`](STEPS.md).

**وإن رُفضتَ أنت أيضًا: قل للمالك فورًا وتوقّف.** لا تحاول حيلةً أخرى.

## ٢ · الحزمة (git bundle) — وكيف تنتقل

المشروعُ ينتقل بين الجلسات كحزمةِ git واحدة:

```bash
git bundle create falah.bundle --all
```

**السلامةُ تُتحقَّق قبل الاعتماد عليها، لا بعده:**

```bash
git bundle verify falah.bundle          # يجب أن يقول: records a complete history
git clone falah.bundle FALAH && cd FALAH
git rev-list --count HEAD               # ٤٢ فأكثر
git ls-files | wc -l                    # ٣٠٠
git branch --show-current               # main
```

### تسميةٌ تبدو غريبةً ولها سبب

تصل الحزمةُ أحيانًا باسم **`falah-bundle.txt`** لا `falah.bundle`.

السبب: المالكُ يعمل من هاتف، وواجهاتُ التنزيل والإرفاق ترفض امتداد
`.bundle` (خارج قائمةٍ مسموحة). **المحتوى هو الحزمةُ نفسُها بايتًا ببايت**
— تحقَّقْ بالبصمة لا بالاسم. و`git clone` يعرف الحزمةَ من محتواها لا من
امتدادها، فلا حاجة إلى إعادة تسمية.

> ⚠ فشلَ إرسالُ الحزمة إلى جلسةٍ سابقةٍ باسم `.bundle` ولم تصل قطّ.
> الاسمُ `.txt` هو الذي ينجح.

## ٣ · طريقُ الاستيراد من المتصفّح

بُني ليعمل **بلا طرفيّةٍ ولا حاسوب**: يرفع المالكُ ملفّين من المتصفّح،
فيقوم GitHub نفسُه بفكّ الحزمة ودفعِها.

- الوصفةُ محفوظةٌ في **`launch/import-workflow.yml`**.
- الخطواتُ للمالك في [`STEPS_WEB.md`](STEPS_WEB.md).

**لا تنسخ هذا الملفَّ إلى `.github/workflows/` في المستودع.** موضعُه هناك
مؤقّتٌ للاستيراد وحدَه، ويزول بعده — لأنّ الدفعَ يستبدل شجرةَ المستودع.

فيه حارسان جُرِّبا فعلًا وأسقطا التشغيلَ كما ينبغي:

1. **حزمةٌ ناقصةٌ أو معطوبة** → يتوقّف قبل أن يمسّ المستودع.
2. **المستودعُ ليس فارغًا** → يتوقّف ولا يمحو شيئًا.

و`--force` فيه **مقصودٌ في موضعه وحدَه**، بعد أن أثبت الحارسُ الثاني أنّ
المستودعَ فارغ. لا تنقله إلى مكانٍ آخر.

### ملاحظةٌ تُوفّر ساعةً من الحيرة

**الدفعُ من داخل GitHub Actions لا يُشغّل أنبوبًا جديدًا** (حمايةٌ من
التكرار اللانهائيّ). فبعد نجاح الاستيراد يجب تشغيلُ `CI` **يدويًّا** مرّةً
واحدة: `Actions ← CI ← Run workflow`. وبعدها كلُّ دفعةٍ تُشغّله وحدَها.

## ٤ · ما يُتوقَّع أن يكون أحمرَ في CI — وليس عطبًا

عند أوّل تشغيلٍ على نسخةٍ نظيفة:

| الوظيفة | المتوقَّع | لماذا |
|---|---|---|
| `static` | ✅ | — |
| `flutter` | ✅ **ومنها الـAPK** | — |
| `tests` | ❌ | تحتاج قاعدةَ محتوًى ١٦٥ م.ب لا تدخل git |
| `build` | ⏭ | مشروطٌ بـ`tests` |
| `QUALITY_GATE` | ❌ | لأنّ `tests` سقطت |

**هذا الأحمرُ صدقٌ لا عطب**، ومقصودٌ: اختبارٌ لم يجرِ لا يُعلَن ناجحًا،
ولم يُجعل يمرّ بالتحايل (راجع §٢٫٦ في `HANDOFF.md`).

> ❌ **فلا «تُصلحه»** بتعطيل الاختبارات، ولا بجعل `tests` تُتخطّى صامتةً،
> ولا بحذف `QUALITY_GATE`. إن أردتَ حلًّا فالحلُّ إتاحةُ قاعدة المحتوى
> للأنبوب — لا إخراسُ الفاحص.

**أمّا `flutter` الحمراء فليست متوقَّعة** — تلك عطبٌ حقيقيٌّ يُحقَّق فيه.

## ٥ · أمانٌ مفتوحٌ الآن — لم يُنجَز بعد

هاتان على المالك لا على الشيفرة، وذُكِّر بهما مرارًا ولم تُنجزا:

1. **المستودعُ عامٌّ** — ورخصةُ التفسير الميسّر لم تُحسم، وهو محفوظُ
   الحقوق لمجمّع الملك فهد. يُجعل خاصًّا حتى تُحسم.
2. **رمزُ وصولٍ شخصيٌّ (PAT) كُتب داخل نصِّ المحادثة** — والمحادثةُ ليست
   عابرة. يجب **إبطالُه**، لا مجرّد تركِه.

> وقاعدةٌ عامّة: لا تقبل من المالك كلمةَ مرورٍ لحسابٍ ولا رمزَ تحقّقٍ
> ثنائيّ. المقبولُ فقط مفاتيحُ واجهةٍ محدودةُ الصلاحيّة قابلةٌ للإبطال
> (Apple: In-App Purchase Key و App Store Connect API Key بدور
> **App Manager** لا Admin · Google: حسابُ خدمةٍ بصلاحيّةِ تطبيقٍ واحد،
> لا مالكُ حسابٍ ولا Admin ولا نشرٌ إلى الإنتاج).

## ٦ · عيوبٌ أُصلحت في هذه الجلسة

تُذكر لأنّ إصلاحها ليس ظاهرًا من الشيفرة وحدَها، ونقضُها سهلٌ بحسن نيّة:

| العيب | الإصلاح | لا تنقضه بـ |
|---|---|---|
| إصدارُ الإنتاج كان يُوقَّع بمفتاح التصحيح (`// TODO` في gradle) | ثلاثُ مساراتٍ للنكهات؛ **الإنتاجُ بلا مفتاحٍ يُسقط البناءَ** لا يُوقَّع بـdebug | إعادةِ `signingConfig` الافتراضيّ |
| `delete_account` كان `try/except pass` فوق خمسة جداول، فيبقى رمزُ تلغرام المختوم | حذفٌ صريحٌ من ستةَ عشرَ جدولًا بلا `except`، **واختبارٌ يقرأ الجداولَ من `sqlite_master`** فيسقط إن نُسي جدولٌ جديد | إضافةِ جدولٍ دون إضافته للحذف |
| `tests.py` (فاحصُ مستودعٍ) كان يُشغَّل داخل صورة Docker فيفشل | `verify_image.py` — الصورةُ تتحقّق من نفسها بأحدَ عشرَ فحصًا وقتَ البناء | إعادةِ `RUN python3 tests.py` |
| `/privacy` و`/terms` كانا 404 داخل الحاوية (`.dockerignore` يستبعد `docs/`) | نسخُ الملفّين صراحةً، **وتثبيتُ الفحص في `verify_image.py`** | حذفِ سطر COPY |
| وحدةُ النشر بلا مسارات HTTP | خمسةُ مساراتٍ بتفويضٍ كامل؛ الثابتُ `OWNER_SCOPE_ENFORCED` سقط بالاسم فحُدِّث بالاسم | — |
| `/app/publish/disconnect` بلا `fields=` فلم يصل معرِّفُ المالك للحارس (400) | أُضيف — **واكتُشف باختبارٍ حيٍّ لا بقراءة الشيفرة** | — |
| `ApiClient` يرفض مصفوفةَ JSON في الجذر | `getList()` | — |
| `.gitignore`: `*.jks` مقصورةٌ على مجلّد android | وُسِّعت: `**/*.jks` · `**/*.keystore` · `**/key.properties` · `**/*.p12` · `**/service-account*.json` | تضييقِها ثانيةً |
