# من المتصفّح وحدَه — بلا طرفيّة

> معك حقّ: GitHub وحده يكفي. هذه الطريقة كلُّها بالمتصفّح على هاتفك.
>
> **الفكرة:** ترفع ملفّين صغيرين، وتضغط زرًّا. فيقوم GitHub نفسُه بفكّ
> المشروع (٤٠ التزامًا · ٢٩٨ ملفًّا) ودفعِه — ثم يختفي الملفّان.
>
> عشر دقائق عمل، وربعُ ساعةٍ انتظار.

---

## ١ · اجعل المستودع خاصًّا (دقيقة)

```
github.com/daood40/FALAH-Flutter-app-Android-iOS-.
  ←  Settings
  ←  انزل إلى آخر الصفحة: Danger Zone
  ←  Change repository visibility  ←  Make private
```

يطلب كتابةَ اسم المستودع للتأكيد — اكتبه **بالنقطة في آخره**.

**لماذا قبل الرفع:** المستودعُ عامٌّ الآن (تحقّقتُ منه قبل قليل)، ورخصةُ
التفسير الميسّر لم تُحسم — وهو محفوظُ الحقوق لمجمّع الملك فهد.

✅ **حين ترى شارة `Private` بجانب الاسم.**

## ٢ · أبطِل الرمز الذي أرسلتَه (دقيقة)

```
github.com  ←  صورتُك  ←  Settings  ←  Developer settings
            ←  Personal access tokens  ←  Fine-grained tokens
            ←  الرمز  ←  Delete
```

**ولن تحتاج إلى رمزٍ بديل في هذه الطريقة** — GitHub يدفع لنفسه.

✅ **حين يختفي من القائمة.**

## ٤ · ارفع الحزمة (دقيقتان)

في صفحة المستودع:

```
Add file  ←  Upload files
```

اختر **`falah.bundle`** من هاتفك.

انزل تحت واضغط **Commit changes**.

> إن لم تجد `Add file`، فأنت في صفحةٍ فرعيّة — ارجع إلى الصفحة الرئيسة
> للمستودع (اضغط اسمه في الأعلى).

✅ **حين ترى `falah.bundle` في قائمة الملفّات.**

---

## ٥ · أنشئ ملفّ الاستيراد (٣ دقائق)

هذا يحتاج **إنشاءَ ملفٍّ بمسارٍ معيّن**، لا رفعًا. اتبع بالضبط:

```
Add file  ←  Create new file
```

في خانة اسم الملفّ أعلى الصفحة، اكتب **هذا بالضبط**:

```
.github/workflows/import.yml
```

> **مهمّ:** اكتب الشرطات المائلة `/` بيدك. GitHub سيحوّلها تلقائيًّا إلى
> مجلّدات وأنت تكتب — ستراها تتقسّم أمامك. هذا هو المطلوب.

ثم في المساحة الكبيرة تحتها: **افتح ملفّ `import.yml` الذي نزّلتَه، وانسخ
محتواه كلَّه، والصقه هنا.**

انزل واضغط **Commit changes** ثم **Commit changes** مرّةً أخرى.

✅ **حين ترى مجلّد `.github` في المستودع.**

## ٦ · شغّل الاستيراد (ضغطة زرّ)

```
تبويب Actions
  ←  من القائمة اليمنى:  استيراد المشروع من الحزمة
  ←  زرّ Run workflow (أزرق، يمين)
  ←  Run workflow
```

انتظر ٣٠–٦٠ ثانية ثم حدّث الصفحة. اضغط على التشغيلة لترى ما يجري.

**ما يفعله:**

1. يتأكّد أنّ الحزمة موجودةٌ وسليمة
2. **يتأكّد أنّ المستودع فارغٌ** — وإن وجد فيه عملًا آخر **توقّف ولم يمحُ شيئًا**
3. يفكّ الحزمة ويدفع ٤٠ التزامًا و٢٩٨ ملفًّا

✅ **حين تصير التشغيلةُ خضراء.**

ارجع إلى صفحة المستودع الرئيسة — ستجد المشروع كلَّه: `falah_app` و`falah`
و`docs` و`Dockerfile`… **وقد اختفى `falah.bundle` و`import.yml`.** هذا
مقصود: استُبدلا بمحتوى الحزمة.

## ٧ · شغّل البناء ليخرج الـAPK

> **لماذا خطوةٌ منفصلة:** الدفعُ من داخل Actions لا يُشغّل أنبوبًا جديدًا
> (حمايةٌ من التكرار اللانهائيّ). فتُشغّله أنت مرّةً واحدة، وبعدها كلُّ
> دفعةٍ تُشغّله وحدَها.

```
تبويب Actions
  ←  من القائمة اليمنى:  CI
  ←  Run workflow  ←  Run workflow
```

انتظر **١٥–٢٥ دقيقة** (أوّلُ مرّةٍ أبطأ — يُنزّل Flutter).

**وسترى هذا، وهو متوقَّعٌ لا عطب:**

| الوظيفة | النتيجة |
|---|---|
| `static` | ✅ أخضر |
| `flutter` | ✅ أخضر ← **منها الـAPK** |
| `tests` | ❌ **أحمر** — يحتاج قاعدةَ المحتوى (١٦٥ م.ب لا تدخل git) |
| `build` | ⏭ يُتخطّى |
| `QUALITY_GATE` | ❌ أحمر |

> **الأحمرُ صدقٌ لا عطب.** اختبارٌ لم يجرِ لا يُعلَن ناجحًا، ولم أجعله
> يمرّ بالتحايل. يُعالَج لاحقًا حين يكون معك حاسوب.

## ٨ · نزّل الـAPK وثبّته

في صفحة التشغيلة، **انزل إلى آخرها** — قسم **Artifacts**:

```
falah-android-staging-apk   ←  اضغط
```

يُنزَّل `.zip`. افتحه بمدير الملفّات وفُكَّه، فتجد:

```
app-staging-release.apk
```

اضغط عليه. سيمنع أندرويد التثبيتَ من هذا المصدر — اضغط **الإعدادات**
واسمح، ثم ارجع وثبّت.

سيظهر باسم **«فَلاح (تجريبيّ)»**.

## ٩ · افتحه

**سيفتح ولن يعمل بعد** — سترى شاشةَ الدخول ثم خطأَ اتّصالٍ عند المحاولة،
لأنه بلا خادمٍ بعد.

**وهذا نجاحٌ لا فشل:** التطبيقُ بُني وثُبِّت واشتغل على جهازك. الخادمُ
خطوةٌ تاليةٌ مستقلّة.

# إن تعثّرت

| ما ترى | المعنى | الحلّ |
|---|---|---|
| `falah.bundle غيرُ موجودة` | لم تُرفع أو رُفعت في مجلّدٍ فرعيّ | ارفعها في **جذر** المستودع |
| `المستودعُ ليس فارغًا` | فيه ملفّاتٌ أخرى | **حارسٌ يحميك** — أخبرني قبل أن تحذف شيئًا |
| `الحزمةُ ناقصة` | نزلت مبتورة | أعِد تنزيلها ورفعها |
| لا أرى «استيراد المشروع» في Actions | مسارُ الملفّ خطأ | يجب أن يكون `.github/workflows/import.yml` بالضبط |
| `flutter` حمراء | **ليست متوقَّعة** | أرسل لي السجلّ |
