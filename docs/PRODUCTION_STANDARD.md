## ١٢ · قواعد سابقة تبقى نافذة

هذه لا يلغيها المعيار بل يُضاف إليها:

| القاعدة | المصدر |
|---|---|
| `SOURCE_LOCK = TRUE` | قائمة منذ البداية — ويؤكّدها هذا المعيار |
| **لا نسخ مصادر مع إزالة نسبة الملكية** — الترخيص أو الإذن، لا غير | مقترح مرفوض ويبقى مرفوضًا |
| لا كلمة مرور حساب أبل أو جوجل ولا رمز تحقّق — مفاتيح مُنطاقة قابلة للإبطال فقط | `launch/CREDENTIALS.md` |
| **الهجرة ٠٠٣ لا تُطبَّق على الإنتاج** إلا عبر `make db-safe-migrate` | `P0_RELEASE_STATUS.md` |
| حواجز الإصدار تبقى ظاهرة ولا تُحسب `PASS` | `P0_RELEASE_STATUS.md` |
| لا إضعاف افتراضات الإنتاج لتمرير اختبار · ولا حذف اختبار صار مزعجًا | قاعدة قائمة |
| `PASS` / `PARTIAL` / `BLOCKED` / `FAIL` — ولا تلميع | قاعدة قائمة |
