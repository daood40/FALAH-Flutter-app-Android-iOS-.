## ترجمة القائمة إلى واقع المشروع

القائمة مكتوبة لـFlutter + Supabase. فلاح ليس كذلك، فتُقرأ هكذا:

| في القائمة | في فلاح |
|---|---|
| Flutter | PWA — `falah-app.html` بلا إطار عمل + قشرة Capacitor غير مبنيّة |
| Supabase / PostgreSQL | SQLite — `app.db` (WAL) + `falah.db` (محتوى، ٢٥٦٫٧ م.ب) |
| RLS | `falah/authz.py` — بوّابتان: صلاحية + نطاق مورِد |
| Backend | Python 3.11 بالمكتبة القياسية + `ThreadingHTTPServer` |
