# خطوةً خطوة — من هاتفك إلى تطبيقٍ مثبَّت

> اتبعها بالترتيب ولا تقفز. الخطواتُ ١–٢ دقائق، و٣–٦ حوالي ربع ساعة،
> والباقي انتظارُ البناء.
>
> **بعد كلِّ أمرٍ في Termux: إن ظهر خطأٌ أحمر، توقّف وأرسله لي.** لا تكمل
> على خطأ — الخطأُ المتروك يظهر بعد خمسِ خطواتٍ في مكانٍ لا علاقةَ له به.

# القسم الأوّل: أمانٌ قبل كلِّ شيء (دقيقتان)

## ١ · أبطِل الرمز الذي أرسلتَه

من المتصفّح على هاتفك:

```
github.com  ←  صورتُك (أعلى اليمين)  ←  Settings
            ←  Developer settings  (آخرُ القائمة)
            ←  Personal access tokens  ←  Fine-grained tokens
            ←  الرمز الذي أرسلتَه  ←  Delete
```

**لماذا:** كتبتَه في المحادثة، والمحادثةُ ليست عابرة. من ملكه دفع شيفرةً
باسمك إلى مستودعاتك.

✅ **تمّت حين لا ترى الرمزَ في القائمة.**

## ٢ · اجعل المستودع خاصًّا

```
github.com/daood40/FALAH-Flutter-app-Android-iOS-.
            ←  Settings  ←  انزل إلى آخر الصفحة (Danger Zone)
            ←  Change repository visibility  ←  Make private
```

يطلب منك كتابةَ اسم المستودع للتأكيد. اكتبه كما هو **بالنقطة في آخره**.

**لماذا الآن:** المستودعُ عامٌّ في هذه اللحظة (تحقّقتُ). ورخصةُ التفسير
الميسّر لم تُحسم بعد — وهو محفوظُ الحقوق لمجمّع الملك فهد. نشرُه على
مستودعٍ عامٍّ أثقلُ من تركه.

✅ **تمّت حين ترى شارة `Private` بجانب اسم المستودع.**

# القسم الثاني: تجهيز Termux (١٠ دقائق)

## ٣ · ثبّت Termux من F-Droid

افتح في المتصفّح:

```
https://f-droid.org/packages/com.termux/
```

اضغط **Download APK**، ثم ثبّته. سيسألك أندرويد عن السماح بالتثبيت من
المتصفّح — اقبل.

> ⚠ **لا تثبّته من متجر Play.** نسخةُ Play قديمةٌ ومهجورةٌ منذ سنوات،
> و`pkg install` فيها يفشل. هذا أشهرُ سببٍ لتعثّر الناس هنا.

✅ **تمّت حين يفتح Termux وترى سطرَ أوامرَ أسود.**

## ٤ · جهّز Termux

افتح Termux واكتب هذا الأمر ثم اضغط Enter:

```bash
pkg update -y && pkg upgrade -y
```

سيسألك أحيانًا سؤالًا فيه `[Y/n]` — اضغط Enter (يعني نعم).
يأخذ دقيقتين إلى خمس.

ثم:

```bash
pkg install git -y
```

ثم:

```bash
termux-setup-storage
```

سيظهر طلبُ إذنٍ من أندرويد للوصول إلى الملفّات — **اقبله**. بدونه لن يرى
Termux الملفَّ الذي ستنزّله.

تحقّق أنّ git رُكِّب:

```bash
git --version
```

✅ **تمّت حين ترى شيئًا مثل `git version 2.4x.x`.**

## ٥ · عرّف git بنفسك

```bash
git config --global user.name "daood40"
git config --global user.email "daoodalfsye@gmail.com"
```

✅ **تمّت بلا مخرَجات — الصمتُ هنا نجاح.**

# القسم الثالث: نقلُ المشروع (٥ دقائق)

## ٦ · نزّل الحزمة

ارجع إلى محادثة Claude، واضغط على ملفّ **`falah.bundle`** لتنزيله.
سيُحفظ عادةً في مجلّد **Download**.

## ٧ · انقلها إلى Termux

في Termux:

```bash
cd ~
cp /sdcard/Download/falah.bundle .
ls -lh falah.bundle
```

يجب أن ترى سطرًا فيه **`2.9M`** تقريبًا.

**إن قال `No such file or directory`** — ابحث عنها:

```bash
find /sdcard -name "falah.bundle" 2>/dev/null
```

سيطبع المسارَ الحقيقيّ. انسخه واستعمله:

```bash
cp <المسار-الذي-ظهر> ~/falah.bundle
```

✅ **تمّت حين يعرض `ls -lh` الملفَّ بحجم ٢٫٩ م.ب.**

## ٨ · فُكَّ الحزمة

```bash
cd ~
git clone falah.bundle FALAH
cd FALAH
```

تحقّق:

```bash
git log --oneline | wc -l
git ls-files | wc -l
git branch --show-current
```

يجب أن ترى:

| السطر | المتوقَّع |
|---|---|
| عددُ الالتزامات | **٣٥ فأكثر** (يزيد كلّما أضفتُ شيئًا) |
| عددُ الملفّات | **٢٩٨** |
| الفرع | **`main`** |

> الرقمُ الأوّلُ يتغيّر ولا يضرّ. والمهمُّ أن يكون الفرعُ `main` وأنّ
> الملفّاتِ نحوَ ٢٩٨ — لو رأيتَ عشراتٍ قليلةً فالحزمةُ نزلت ناقصةً، أعِد
> تنزيلها.

✅ **تمّت حين تكون داخل مجلّد `FALAH` والأعدادُ صحيحة.**

# القسم الرابع: الدفع (٥ دقائق)

## ٩ · ولّد رمزًا جديدًا

من المتصفّح:

```
github.com  ←  Settings  ←  Developer settings
            ←  Personal access tokens  ←  Tokens (classic)
            ←  Generate new token  ←  Generate new token (classic)
```

املأ:

| الحقل | القيمة |
|---|---|
| **Note** | `termux-falah` |
| **Expiration** | `90 days` |
| **Scopes** | ✅ **`repo`** فقط — لا تعلّم غيره |

اضغط **Generate token** في آخر الصفحة.

> ⚠ **انسخ الرمزَ فورًا** — لن يظهر مرّةً ثانيةً أبدًا. الصقه في مكانٍ
> مؤقّت (ملاحظة على هاتفك) حتى تنتهي الخطوةُ التالية، ثم احذفه من هناك.
>
> ⚠ **ولا ترسله إليّ ولا إلى أحد.**

## ١٠ · اربط المستودع وادفع

في Termux:

```bash
cd ~/FALAH
git remote add origin https://github.com/daood40/FALAH-Flutter-app-Android-iOS-..git
git push -u origin main
```

> النقطتان في `-..git` **صحيحتان**: نقطةُ اسم المستودع، ثم `.git`.
> تحقّقتُ من الاسم بنفسي.

سيسألك سؤالين:

```
Username for 'https://github.com':     ←  اكتب:  daood40
Password for 'https://daood40@github.com':  ←  الصق الرمزَ الجديد
```

> **الرمزُ لن يظهر وأنت تلصقه** — لا نجومَ ولا حروف. هذا طبيعيّ. الصق
> واضغط Enter.

سترى شريطَ تقدُّمٍ ثم شيئًا مثل:

```
Enumerating objects: 900, done.
...
To https://github.com/daood40/FALAH-Flutter-app-Android-iOS-..git
 * [new branch]      main -> main
branch 'main' set up to track 'origin/main'.
```

✅ **تمّت حين ترى `* [new branch] main -> main`.**

### إن فشل

| الرسالة | المعنى | الحلّ |
|---|---|---|
| `Authentication failed` | الرمزُ خطأ أو بلا `repo` | ولّد رمزًا جديدًا وتأكّد من `repo` |
| `Repository not found` | خطأٌ في الرابط | تأكّد من النقطتين `-..git` |
| `Updates were rejected` | في المستودع شيءٌ سابق | `git pull origin main --allow-unrelated-histories` ثم أعِد الدفع |
| `remote: Support for password authentication was removed` | كتبتَ كلمةَ مرورِ حسابك | الرمزُ مكانَ كلمة المرور لا كلمةُ المرور |

> ❌ **ولا تستعمل `git push --force` أبدًا** — تمحو ما في المستودع بلا رجعة.

## ١١ · احذف الرمز من الملاحظة

بعد نجاح الدفع، احذف الرمزَ من مكانه المؤقّت على هاتفك. (git حفظه لك إن
شئت بـ`git config --global credential.helper store`، لكنه يُحفظ بنصٍّ
صريحٍ — لا تفعلها إن كان أحدٌ يستعمل هاتفك.)

# القسم الخامس: أوّلُ تطبيقٍ على جهازك (١٥–٢٥ دقيقة انتظار)

## ١٢ · افتح Actions

```
github.com/daood40/FALAH-Flutter-app-Android-iOS-.  ←  تبويب Actions
```

ستجد تشغيلةً بدأت وحدَها. اضغط عليها.

**وستراها هكذا — وهذا متوقَّعٌ لا عطب:**

| الوظيفة | النتيجة | لماذا |
|---|---|---|
| `static` | ✅ أخضر | — |
| `flutter` | ✅ أخضر **← منها الـAPK** | — |
| `tests` | ❌ **أحمر** | يحتاج قاعدة المحتوى (١٦٥ م.ب لا تدخل git) |
| `build` | ⏭ يُتخطّى | مشروطٌ بـ`tests` |
| `QUALITY_GATE` | ❌ أحمر | لأنّ `tests` سقطت |

> **الأحمرُ هنا صدقٌ لا عطب.** الاختبارُ الذي لم يجرِ لا يُعلَن ناجحًا،
> ولم أجعله يمرّ بالتحايل. وسنعالجه لاحقًا حين يكون معك حاسوب.

## ١٣ · نزّل الـAPK

انتظر حتى تصير `flutter` خضراء (١٥–٢٥ دقيقة أوّلَ مرّة).

ثم **انزل إلى آخر صفحة التشغيلة** — قسم **Artifacts**:

```
falah-android-staging-apk   ←  اضغط لتنزيله
```

يُنزَّل ملفَّ `.zip`. افتحه بمدير الملفّات وفُكَّه، ستجد داخله:

```
app-staging-release.apk
```

## ١٤ · ثبّته

اضغط على الـAPK. سيقول أندرويد إنّ التثبيت من هذا المصدر ممنوع — اضغط
**الإعدادات** واسمح، ثم ارجع وثبّت.

سيظهر التطبيقُ باسم **«فَلاح (تجريبيّ)»**.

> المعرِّفُ `com.falah.app.staging` مختلفٌ عن معرِّف الإنتاج عمدًا — فلا
> يمكن رفعُه للمتجر، ويمكن تثبيتُ نسخة المتجر بجانبه لاحقًا.

## ١٥ · افتحه

**سيفتح ولن يعمل بعد** — لأنه يحتاج خادمًا، ولا خادمَ لك بعد. سترى شاشةَ
الدخول ثم خطأَ اتّصال عند المحاولة.

**وهذا نجاحٌ لا فشل:** يعني أنّ التطبيقَ بُني وثُبِّت واشتغل على جهازك.

✅ **تمّت حين ترى شاشةَ فَلاح على هاتفك.**
