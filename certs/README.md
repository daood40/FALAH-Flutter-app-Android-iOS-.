# شهاداتٌ إضافيّةٌ تثق بها الصورة

ضع هنا ملفَّ `.crt` واحدًا أو أكثر (بترميز PEM) إن كانت شبكتُك تعترض TLS —
وسيطُ شركةٍ أو جدارُ حمايةٍ يفحص الاتّصال. الصورةُ تُدخلها في مخزنِ الثقة
عند البناء، فينجح `pip` و`playwright` من خلف الوسيط.

**والمجلَّدُ فارغٌ افتراضيًّا**، فلا تتغيّر ثقةُ الصورة بشيء ما لم تضع أنت
ملفًّا. وهذا ليس تخفيفًا للتحقّق من الشهادات: الشهادةُ تُضاف إلى المخزن،
ولا يُعطَّل التحقّقُ بحال — لا `--trusted-host` ولا `verify=False`.

    cp /path/to/corporate-ca.crt certs/
    docker build -t falah .

**ولا تُودَع الشهاداتُ في git**: `.gitignore` يمنع `certs/*.crt`، لأنّ شهادةَ
وسيطِ مؤسّسةٍ معلومةٌ عن بنيتها الداخليّة لا تُنشر.
