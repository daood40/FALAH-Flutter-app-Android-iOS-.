# HTML دلالي صحيح

مسار الويب (HTML/CSS/JS) — ليس Flutter. القاعدة الحاكمة: **العنصر الصحيح يعطيك مجاناً ما ستكتبه بـ 40 سطر JS**: التركيز بلوحة المفاتيح، الإعلان لقارئ الشاشة، السلوك الافتراضي، وفهم محرك البحث.

## العناصر الدلالية ومتى تُستعمل

| العنصر | يُستعمل لـ | لا يُستعمل لـ |
|---|---|---|
| `<header>` | ترويسة الصفحة أو ترويسة `article`/`section` | أي شريط في أعلى أي صندوق |
| `<nav>` | كتلة روابط تنقّل رئيسية | كل مجموعة روابط (الحد: 1–3 في الصفحة) |
| `<main>` | المحتوى الفريد للصفحة — **مرة واحدة فقط** | تكراره في نفس الصفحة |
| `<article>` | وحدة مستقلة تصلح للنشر وحدها (مقال، منتج، تعليق) | تقسيم بصري |
| `<section>` | كتلة موضوعية **لها عنوان** | بديل عن `div` بلا عنوان |
| `<aside>` | محتوى جانبي مكمّل | العمود الأيسر لمجرد أنه جانبي |
| `<footer>` | تذييل الصفحة أو تذييل قسم | — |
| `<figure>`/`<figcaption>` | صورة/رسم مع تعليق مرتبط | صورة بلا تعليق |
| `<time datetime="...">` | تاريخ أو وقت قابل للقراءة آلياً | — |
| `<dialog>` | حوار/نافذة منبثقة | — |

قاعدة الفصل: `section` بلا `<h2>` بداخله = يجب أن يكون `div`. و`div` و`span` ليسا خطأ — هما الأداة الصحيحة عندما يكون الغرض **تخطيطياً بحتاً**.

## بنية العناوين h1–h6

- `<h1>` واحد لكل صفحة، ويصف موضوع الصفحة لا اسم الموقع.
- **لا تقفز مستوى**: بعد `h2` يأتي `h3` أو `h2`، لا `h4`. القفز يكسر تنقّل قارئ الشاشة بين العناوين.
- المستوى يحدده **العمق المنطقي**، لا الحجم البصري. تريد عنواناً صغيراً؟ صغّره بـ CSS ولا تنزل لـ `h5`.
- العنوان لا يكون فارغاً ولا صورة بلا بديل.

اختبار سريع: استخرج العناوين وحدها؛ يجب أن تُقرأ كفهرس مفهوم للصفحة.

```html
<h1>متجر قطع غيار</h1>
  <h2>المنتجات</h2>
    <h3>فلاتر الزيت</h3>
    <h3>البطاريات</h3>
  <h2>الشحن والدفع</h2>
```

## المعالم (landmarks)

المعالم هي ما يستعمله قارئ الشاشة للقفز بين مناطق الصفحة. الحد الأدنى في كل صفحة: `header` + `nav` + `main` + `footer`.

- إن تكرر عنصر معلم (مثل `nav` مرتين) فكل واحد يحتاج `aria-label` مميزاً: `aria-label="التنقل الرئيسي"` و`aria-label="روابط التذييل"`.
- رابط "تخطّي إلى المحتوى" أول عنصر قابل للتركيز في الصفحة، يشير إلى `#main`، ويظهر عند `:focus` فقط.
- لا تضع `role="navigation"` على `<nav>` — الدور ضمني، والتكرار ضجيج.

## القوائم والجداول

- كل مجموعة عناصر متكررة (بطاقات منتجات، روابط، خطوات) = `<ul>`/`<ol>` مع `<li>`. قارئ الشاشة يعلن "قائمة من 12 عنصراً" وهي معلومة حقيقية.
- الابن المباشر لـ `<ul>` يجب أن يكون `<li>` فقط.
- الجدول لبيانات ذات صفوف وأعمدة **فقط**، لا للتخطيط.

```html
<table>
  <caption>مبيعات الربع الأول</caption>
  <thead>
    <tr><th scope="col">الشهر</th><th scope="col">المبيعات</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">يناير</th><td>1,250</td></tr>
  </tbody>
</table>
```

`<caption>` و`scope` غير اختياريين في جدول حقيقي: بدونهما لا يعرف قارئ الشاشة أي خلية تخص أي عمود.

## الصور والبدائل النصية

| الحالة | `alt` |
|---|---|
| صورة تحمل معلومة | وصف المعلومة، 5–15 كلمة، بلا "صورة لـ" |
| صورة زخرفية بحتة | `alt=""` (فارغ، وليس محذوفاً) |
| صورة داخل رابط بلا نص | وصف **وجهة الرابط** لا الصورة |
| رسم بياني | ملخص الاستنتاج، والتفاصيل في نص مجاور |
| شعار في الترويسة | اسم الموقع |

حذف `alt` نهائياً يجعل قارئ الشاشة ينطق اسم الملف — أسوأ من الفراغ. وأضف دائماً `width` و`height` على `<img>` لمنع قفز التخطيط.

## الروابط مقابل الأزرار — الخطأ الأشهر

| ينتقل إلى عنوان (URL) | يغيّر شيئاً في الصفحة |
|---|---|
| `<a href="...">` | `<button type="button">` |
| يُفتح في تبويب جديد، يُنسخ، يُفهرس | لا معنى لفتحه في تبويب |
| مفتاح Enter يفعّله | Enter و**Space** يفعّلانه |

القاعدة: `<div onclick>` أو `<a href="#">` لفتح قائمة = خطأ. `<div>` غير قابل للتركيز، لا يستجيب للوحة المفاتيح، ولا يُعلن كزر. وداخل النموذج، `<button>` بلا `type` يعني `type="submit"` — وهذا سبب متكرر لإرسال النموذج بالخطأ عند الضغط على زر "إضافة صف".

## النماذج وربط التسميات

كل حقل إدخال يحتاج تسمية مرتبطة. `placeholder` ليس تسمية: يختفي عند الكتابة وتباينه ضعيف.

```html
<label for="phone">رقم الهاتف</label>
<input id="phone" name="phone" type="tel"
       inputmode="numeric" autocomplete="tel"
       aria-describedby="phone-hint phone-err">
<p id="phone-hint">مثال: 0912345678</p>
<p id="phone-err" role="alert"></p>
```

- `type` الصحيح يغيّر لوحة المفاتيح على الجوال: `tel`, `email`, `url`, `number`, `search`.
- `autocomplete` بقيم قياسية (`name`, `email`, `tel`, `street-address`, `one-time-code`) يوفّر على المستخدم نصف الوقت.
- رسالة الخطأ تُربط بـ `aria-describedby`، والحقل الخاطئ يأخذ `aria-invalid="true"`.
- المجموعات (راديو/اختيارات) داخل `<fieldset>` مع `<legend>`.

## lang وdir للعربية

```html
<html lang="ar" dir="rtl">
```

- `lang="ar"` يحدد نطق قارئ الشاشة وفصل الكلمات؛ بدونه يُقرأ النص العربي بلكنة إنجليزية أو لا يُقرأ.
- المقاطع الإنجليزية داخل صفحة عربية: `<span lang="en" dir="ltr">Supabase</span>`.
- الأرقام والرموز المختلطة (`+218 91 234 5678`، `IBAN`) تحتاج `dir="ltr"` أو `<bdi>` لمنع انقلاب ترتيب المقاطع.
- ليبيا تستخدم الأرقام اللاتينية (0–9) عادة؛ لا تفرض الأرقام العربية-الهندية إلا بطلب صريح.
- لا تحل مشاكل الاتجاه بـ CSS فقط: `dir` سمة HTML وهي مصدر الحقيقة لخوارزمية bidi.

## البيانات الوصفية في head

```html
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>عنوان الصفحة — اسم الموقع</title>
<meta name="description" content="وصف 120–155 حرفاً">
<link rel="canonical" href="https://example.ly/page">
<meta property="og:title" content="...">
<meta property="og:image" content="https://example.ly/og.png">
```

`charset` أول شيء في `<head>` (خلال أول 1024 بايت) وإلا ظهر النص العربي كمحارف مشوّهة. و`viewport` بدونها تُعرض الصفحة بعرض 980px مصغّرة على الجوال.

## تكلفة "div لكل شيء"

| ما تخسره | التفصيل |
|---|---|
| الإتاحة | لا معالم للقفز، لا إعلان أدوار، لا تنقّل بالعناوين |
| لوحة المفاتيح | `div` لا يدخل ترتيب التركيز؛ تحتاج `tabindex` + معالجات Enter/Space يدوياً |
| SEO | محرك البحث يستخرج العناوين والروابط والقوائم؛ الحساء غير الدلالي يقلّل ما يفهمه |
| الصيانة | كل سلوك افتراضي مفقود يصير كوداً تكتبه وتصلحه |
| الطباعة والقارئ المبسّط | وضع القراءة يعتمد على `article` و`h1` |

## أخطاء شائعة

- `<a href="#">` لزر لا ينتقل؛ استخدم `<button>`.
- استخدام `<br>` لصنع مسافات بدل CSS.
- `<h3>` لأن الحجم مناسب، مع تخطي `h2`.
- `placeholder` بدل `<label>`.
- `role` و`aria-*` فوق عنصر دلالي يحمل الدور أصلاً — الزائد يضرّ.
- `<section>` بلا عنوان في كل مكان؛ الأصل `div`.
- نسيان `alt=""` على الأيقونات الزخرفية فتُقرأ أسماء ملفات SVG.

## قائمة تحقق

- [ ] `<html lang="ar" dir="rtl">` موجودة، والمقاطع الإنجليزية معلّمة بـ `lang`/`dir`
- [ ] `h1` واحد، ولا قفز في مستويات العناوين
- [ ] `header` + `nav` + `main` (مرة واحدة) + `footer` موجودة، والمعالم المكررة لها `aria-label`
- [ ] رابط "تخطّي إلى المحتوى" أول عنصر قابل للتركيز
- [ ] كل مجموعة متكررة داخل `ul`/`ol`، وكل جدول له `caption` و`th scope`
- [ ] كل `<img>` لها `alt` مناسب (أو `alt=""`) و`width`/`height`
- [ ] كل تنقّل `<a href>` وكل إجراء `<button>` بـ `type` صريح
- [ ] كل حقل له `<label for>` + `type` + `autocomplete` مناسبان
- [ ] رسائل الخطأ مرتبطة بـ `aria-describedby` و`aria-invalid`
- [ ] `charset` و`viewport` و`title` و`description` و`canonical` في `<head>`
- [ ] تنقّلت في الصفحة بـ Tab فقط ووصلت لكل عنصر تفاعلي بترتيب منطقي
