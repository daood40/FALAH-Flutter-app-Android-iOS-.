# تدقيق تراخيص مصادر فلاح

*آخر تحديث: ٢ سبتمبر ٢٠٢٦ — تدقيقٌ تقنيّ لا رأيَ محامٍ. القرار النهائي
يحتاج مراجعة قانونية في بلد التشغيل.*

## الخلاصة في سطر

مصدرٌ واحد مرخَّصٌ صراحةً ويكفيك (نصّ القرآن)، وثلاثة تحتاج إذنًا قبل أي
إطلاقٍ عامّ أو تحقيق دخل، وخمسة تحتاج توضيحًا مكتوبًا. لذلك: **الإطلاق
المغلق اليوم، والعامّ بعد الردود.**

## ١) نصّ القرآن الكريم — مشروع تنزيل

| | |
|---|---|
| المصدر | Tanzil.net (عبر Al Quran Cloud) — الرسم العثماني، حفص عن عاصم |
| الترخيص | **المشاع الإبداعي — النسب ٣٫٠ (CC BY 3.0)** |
| الاستخدام التجاري | **مسموح** |
| الشروط | نسخٌ **حرفيّ بلا تغيير**، وذكرُ المصدر (Tanzil Project) بوضوح، ورابطٌ إلى tanzil.net، وإبقاء إشعار حقوق النشر |
| حالنا | ✅ مستوفًى: النصّ يُعرض حرفيًّا (قفل المصدر يمنع تغيير حرفٍ منه)، وصفحة «المصادر» في التطبيق تنسبه وتضع رابطه |
| الإجراء | لا شيء — إبقاء النسبة والرابط ظاهرين |

## ٢) المصدر المرجعي الثاني للقرآن — Quran.com API v4

| | |
|---|---|
| الدور | مقارنةٌ للتحقّق فقط، لا يُعرض منه شيء |
| الحالة | يحتاج توضيحًا مكتوبًا لشروط الاستخدام البرمجيّ |
| الإجراء | رسالةٌ إلى فريق Quran.com / Quran Foundation — نموذج `letters/quran-com.md` |
| المخاطرة | **منخفضة** — لا يُنشر منه نصّ، وهو مطابقٌ لنصّ تنزيل |

## ٣) التفسير الميسر

| | |
|---|---|
| الناشر | مجمع الملك فهد لطباعة المصحف الشريف |
| الحالة | **محفوظ الحقوق — يحتاج إذنًا صريحًا**، خصوصًا مع أي دخل |
| الإجراء | خطاب إذن — `letters/tafsir-muyassar.md` |
| البديل ريثما يصل الإذن | **إطفاء التفسير في البطاقة** (خيارٌ موجود: `show_tafsir=false`) |
| المخاطرة | **عالية** إن نُشر تجاريًّا بلا إذن |

## ٥) الكتب التسعة — نصوص مفهرسة (hadith-json) و ٦) أحكام المحدِّثين (hadith-api)

| | |
|---|---|
| الأصل | بيانات Sunnah.com |
| الحالة | Sunnah.com يشترط **مفتاح API** ويطلب التواصل؛ ولم يُنشر ترخيصٌ صريح للاستخدام التجاري، وملكية الترجمات الإنجليزية غير موضّحة |
| الإجراء | ١) طلب مفتاح ٢) رسالة توضيح — `letters/sunnah-com.md` |
| ملاحظة | **متون الأحاديث العربية قديمة الملكية العامة**؛ المحلّ للنقاش هو *الترجمة* و*الترقيم* و*الأحكام المنسوبة* في نسخهم |
| البديل ريثما يصل الردّ | إطفاء الترجمة الإنجليزية للحديث، والإبقاء على المتن العربي بترقيمه المشهور |

## ٧) الجامع الكامل في الحديث الصحيح الشامل — ضياء الرحمن الأعظمي

| | |
|---|---|
| الوضع | كتابٌ حديثُ التأليف، **محفوظ الحقوق**؛ ونسختنا نصٌّ ممسوح آليًّا من أرشيف الإنترنت |
| دوره عندنا | **شاهدٌ لا مصدرَ نصّ** — لا يُطبع منه حرفٌ على بطاقة، وإنما يُقرأ منه: المجلد، والباب، والتخريج، ولفظ الحكم |
| الحالة | يحتاج إذنًا لعرض *التخريج والحكم* المنسوبين إليه علنًا |
| الإجراء | خطاب إلى الناشر/الورثة — `letters/jami-azami.md` |
| البديل | إبقاؤه في المحرّك للتحقّق الداخلي (يحجب المتعارض) دون عرض تخريجه على البطاقة |

## ما يُطلق اليوم وما ينتظر

| المكوّن | الإطلاق المغلق (دعوة) | الإطلاق العامّ | التجاري |
|---|---|---|---|
| بطاقات القرآن (النصّ وحده) | ✅ | ✅ | ✅ |
| التفسير على البطاقة | ✅ | ⏸ حتى الإذن | ⛔ |
| الترجمة الإنجليزية للقرآن | ✅ | ⏸ | ⛔ |
| متون الأحاديث العربية | ✅ | ✅ | ✅ |
| ترجمة الحديث الإنجليزية | ✅ | ⏸ | ⛔ |
| تخريج الأعظمي وحكمه على البطاقة | ✅ | ⏸ | ⛔ |
| شرح الموسوعة الحديثية | ✅ | ⏸ | ⏸ |
| فيديو بتلاوة قارئ | ✅ لنفسك | ⏸ | ⛔ |

«✅» في العمود الأول تعني: استعمالٌ خاصّ محدود بمن تدعوهم، مع نسبة كل نصٍّ
لمصدره — وهو أقرب للاستعمال الشخصي منه للنشر. وليست فتوى قانونية.
