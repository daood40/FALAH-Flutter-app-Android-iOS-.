# memory/PROJECT_MEMORY.md   (آخر تحديث: 2026-09-09)

## ما هو
فَلاح يُنشئ بطاقاتٍ ومقاطعَ من نصوصٍ شرعيّةٍ موثَّقةِ الإسناد — قرآنٍ وحديثٍ
من مصادرَ مسجَّلةٍ بأسمائها — ثم يجدولها ويَنشرها. لمن يَنشر نصًّا شرعيًّا
ولا يقبل أن يُنسب إليه تحريف.

## المكدّس
خادم: Python 3.11 · مكتبةٌ قياسيّةٌ + ٤ حزم · ٣٢ وحدةً في `falah/`
عميل: Flutter 3.47 · Riverpod · GoRouter · ١٢ شاشة
قاعدة: SQLite — محتوًى (`falah.db`) + تطبيق (`app.db`)
نشر: Docker Compose — خادم · عامل · نسخٌ احتياطيّ · Caddy

## الحالة اليوم
- **يعمل:** الخادمُ يُقلع ويخدم · البناءُ يُخرج APK مثبَّتًا على جهاز ·
  البوّابةُ ٦ فواحصَ خضراء · ١٩ ثابتًا أمنيًّا · ١٦٤ فحصًا في أربع حزم.
- **لا يعمل:** لا خادمَ منشورٌ على نطاق، فالتطبيقُ يفتح ولا يتّصل. ولا بناءَ
  iOS (يحتاج macOS). ولا حزمةَ متجرٍ موقَّعة (لا مفتاحَ رفع).
- **مُطفأٌ عمدًا:** التفسيرُ والترجمةُ والحديثُ والتلاواتُ — لم تصل أذونُها.
  فالمعروضُ اليومَ **القرآنُ وحدَه**. راجع `DECISIONS.md` ADR-002.
